# אפיון מוצר — "מנדטים 2026" (election-voting)

גרסה 0.1 · 21.10.2026 · סטטוס: טיוטה לאישור

## 1. מהות המוצר

אתר מובייל-first בעברית שבו כל משתמש "מצביע" על התחזית שלו לבחירות לכנסת ה-26 (27.10.2026):

1. איך יתחלקו **120 המנדטים** בין הרשימות (סליידרים, סכום מוגבל ל-120).
2. **מי יהיה ראש הממשלה** (בחירה מתפריט סגור, כולל אופציה "בחירות נוספות").

כל ההצבעות נשמרות ב-DB ומוצגות כתמונה מצרפית (ממוצע המנדטים של כל המשתתפים, התפלגות בחירת רה"מ). אין התחברות: רישום בשם בלבד.

## 2. למי זה מיועד

- חברים ומשפחה שמקבלים קישור. סדר גודל: עשרות עד מאות משתתפים.
- שימוש כמעט רק מהטלפון, בדפדפן (ללא אפליקציה).

## 3. זרימת משתמש

### 3.1 כניסה (ללא התחברות)
- מסך פתיחה: כותרת, הסבר בשתי שורות, שדה **שם** (2–30 תווים), כפתור "להצבעה".
- השם ייחודי (השוואה ללא רישיות ורווחים מיותרים). אם תפוס: "השם תפוס, נסה 'דני כ.'".
- הדפדפן שומר `deviceToken` ב-localStorage. חזרה מאותו מכשיר → ישר למסך ההצבעה שלי (עריכה). מכשיר אחר עם שם קיים → נדרש שם אחר (אין שחזור, בכוונה. פשטות על פני אבטחה).

### 3.2 חלוקת מנדטים
- כרטיס לכל רשימה: צבע גוש, שם הרשימה, אות הפתק, ראש הרשימה, **סליידר** 0–120 עם המספר הנוכחי בגדול, וכפתורי −/+ לדיוק.
- **מונה דביק** בראש המסך: `הוקצו 112 / 120 · נותרו 8`. הסליידר של כל רשימה חסום במקסימום של (הערך הנוכחי שלה + הנותר), כך שהסכום לא יכול לעבור 120.
- **אחוז חסימה**: רשימה מקבלת 0 או לפחות 4 מנדטים (3.25% ≈ 4). הסליידר קופץ מ-0 ישר ל-4. (ניתן לכיבוי בהגדרות.)
- כפתורי עזר: "התחל מהסקרים" (ברירת המחדל בכניסה ראשונה: ממוצע סקרי 19.10), "אפס הכול".
- כפתור "המשך" פעיל רק כשהסכום בדיוק 120.

### 3.3 בחירת ראש ממשלה
- רשימת radio עם תמונה/ראשי תיבות, שם ומפלגה.
- אופציה אחרונה קבועה: **"בחירות נוספות"** (אף אחד לא מרכיב ממשלה והולכים לסבב נוסף).
- הרשימה ניתנת לעריכה מהאדמין (ברירת מחדל בסעיף 5).

### 3.4 שליחה ותוצאות
- אישור → שמירה → מסך **תוצאות**:
  - "ההצבעה שלי" מול "ממוצע כולם" (גרף עמודות אופקי, RTL).
  - התפלגות בחירת רה"מ (אחוזים).
  - מספר המשתתפים, רשימת השמות שהצביעו (ללא פירוט הצבעה של אחרים — ברירת מחדל, ניתן לשינוי).
  - כפתור "ערוך את ההצבעה שלי" עד הנעילה.
  - כפתור שיתוף (Web Share API / העתקת קישור).
- **נעילה**: ברירת מחדל 27.10.2026 22:00 (סגירת הקלפיות). אחרי הנעילה ההצבעות לקריאה בלבד.
- **אחרי התוצאות האמיתיות** (שלב 2): האדמין מזין את התוצאות, המערכת מחשבת ניקוד לכל משתתף (סכום הסטיות המוחלטות במנדטים, בונוס על רה"מ נכון) ומציגה **לוח מובילים**.

## 6. אדמין (מינימלי)

- נתיב `/admin`, גישה בסיסמה אחת (`ADMIN_SECRET` במשתני סביבה).
- פעולות: נעילה/פתיחה של ההצבעה, עריכת רשימות ומועמדים (JSON), הזנת תוצאות אמת, מחיקת משתמש.

## 7. דרישות לא פונקציונליות

- עברית, RTL מלא, רוחב מינימלי 360px, יעד Lighthouse ≥ 90 במובייל.
- ללא מידע אישי מעבר לשם. אין אימייל/טלפון.
- הגנות בסיסיות: rate-limit על רישום (10 לדקה ל-IP), ולידציה בשרת (סכום 120, חסימה, מועמד מהרשימה), שם אחד = הצבעה אחת.
- תוצאות מצרפיות מחושבות בשרת ונשמרות ב-cache ל-10 שניות. רענון בפולינג כל 30 שניות (ללא websockets).

## 8. טכנולוגיה והטמעה

- **Next.js 15** (App Router) + TypeScript + Tailwind. ספריית גרפים קלה (Recharts).
- **DB**: SQLite קובץ (Prisma), בנפח docker. אותו דפוס כמו family-hub.
- **Deploy**: Docker Compose על almog-server, Cloudflare Tunnel → `vote.almog.uk` (הבעלים מוסיף route). CI: GitHub Actions → runner עצמאי, כמו family-hub.
- Repo: `github.com/AlmogEdri/election-voting`, פרויקט ב-AI Development Hub (`~/hub/projects/election-voting`), פיתוח דרך Flow: planner → developer → QA.

### מודל נתונים
```
users(id, name, name_norm UNIQUE, device_token, created_at)
parties(id, name, letters, leader, color, bloc, sort, active, withdrawn)
pm_candidates(id, name, party_id NULL, sort, active)       -- "בחירות נוספות" = שורה קבועה
votes(id, user_id UNIQUE, seats JSON {party_id: n}, pm_candidate_id, updated_at)
settings(key PRIMARY KEY, value JSON)                       -- locked_at, real_results, min_seats
```

### API
```
POST /api/register        {name} → {userId, deviceToken}
GET  /api/me              (header x-device-token) → {user, vote}
PUT  /api/vote            {seats, pmCandidateId} → 200 | 400 (validation) | 423 (locked)
GET  /api/parties         → רשימות + מועמדים
GET  /api/stats           → {participants, avgSeats, pmShare, names[]}
POST /api/admin/*         (header x-admin-secret)
```
